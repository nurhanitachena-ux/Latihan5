1

ความหมายของคำนาม (Kata Nama)

Kata Nama หมายถึง คำที่ใช้เรียกชื่อคน สัตว์ สิ่งของ สถานที่ หรือสิ่งที่เป็นนามธรรม

ตัวอย่าง

orang = คน
guru = ครู
murid = นักเรียน
kucing = แมว
buku = หนังสือ
sekolah = โรงเรียน
masjid = มัสยิด
kebahagiaan = ความสุข
💡 จำง่าย ๆ: Kata Nama = คำที่ใช้ “เรียกชื่อ” สิ่งต่าง ๆ
2

ประเภทของคำนาม

คำนามในภาษามลายูแบ่งออกได้หลายประเภทตามลักษณะการใช้งาน โดยหลัก ๆ มีดังนี้

Kata Nama Am — คำนามทั่วไป
Kata Nama Khas — คำนามเฉพาะ
Kata Nama Konkret — คำนามรูปธรรม
Kata Nama Abstrak — คำนามนามธรรม
💡 รายละเอียดของแต่ละประเภทจะกล่าวถึงในหัวข้อถัดไป
3

คำนามทั่วไปและคำนามเฉพาะ

A. Kata Nama Am — คำนามทั่วไป

ใช้เรียกชื่อบุคคล สัตว์ สิ่งของ หรือสถานที่โดยทั่วไป

guru = ครู
murid = นักเรียน
sekolah = โรงเรียน
buku = หนังสือ
kucing = แมว
kereta = รถยนต์
✏️ Guru mengajar murid di dalam kelas. (ครูกำลังสอนนักเรียนในห้องเรียน)

B. Kata Nama Khas — คำนามเฉพาะ

ใช้เรียกชื่อเฉพาะของบุคคล สถานที่ องค์กร หรือสิ่งต่าง ๆ มักขึ้นต้นด้วยตัวพิมพ์ใหญ่

Ahmad = อาหมัด
Fatimah = ฟาตีมะห์
Malaysia = ประเทศมาเลเซีย
Thailand = ประเทศไทย
Yala = ยะลา
Universiti Rajabhat Yala = ม.ราชภัฏยะลา
✏️ Ahmad pergi ke Yala. (อาหมัดไปยะลา)
4

คำนามรูปธรรมและนามธรรม

Kata Nama Konkret — คำนามรูปธรรม

สิ่งที่สามารถมองเห็นหรือสัมผัสได้

meja = โต๊ะ
kerusi = เก้าอี้
buku = หนังสือ
rumah = บ้าน
telefon = โทรศัพท์

Kata Nama Abstrak — คำนามนามธรรม

สิ่งที่ไม่สามารถจับต้องได้

kasih sayang = ความรัก
kebahagiaan = ความสุข
keberanian = ความกล้าหาญ
kecantikan = ความสวยงาม
kesabaran = ความอดทน
5

ตัวอย่างการใช้ Kata Nama ในประโยค

✏️ Murid membaca buku.
Murid = นักเรียน (คำนาม), buku = หนังสือ (คำนาม)
✏️ Fatimah pergi ke sekolah.
Fatimah = คำนามเฉพาะ, sekolah = คำนามทั่วไป
✏️ Kebahagiaan sangat penting dalam kehidupan.
Kebahagiaan = ความสุข เป็นคำนามนามธรรม
